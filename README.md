# MuzLib — Моя музыкальная библиотека 🎵

**MuzLib** — это мини‑проект, который подключается к базе данных и отображает заранее заданные данные (например, список песен, альбомов или плейлистов) через веб‑интерфейс.  
Идея проста: показать, как можно связать **FastAPI** + **PostgreSQL** и вывести данные на сайт.  

Проект - учебный, но его можно расширять:
- добавить возможность редактировать и добавлять записи прямо с сайта;
- реализовать полноценную систему плейлистов;
- подключить авторизацию пользователей;
- улучшить внешний вид с помощью более замороченного CSS.

## Возможности
- Отображение данных из базы (песни, альбомы, плейлисты).
- Чистая архитектура: FastAPI + SQLAlchemy ORM.
- Деплой на **Render.com** (веб‑сервис + база данных).
- Возможность расширения функционала (CRUD‑операции через сайт).
- Поддержка модульного дизайна и чистой структуры проекта.

## Технологии
- **Backend:** FastAPI (Python)
- **Database:** PostgreSQL (Render.com)
- **ORM:** SQLAlchemy
- **Frontend:** HTML + CSS
- **Deployment:** Render.com (Web Service + Database)
- **IDE:** IntelliJ IDEA / PyCharm
